# Жилищная уязвимость домохозяйств: 2021–2024 — версия v3

Проект предварительного анализа синтетических данных Datathon.
Исследуем связи состава семьи, жилищных условий, удовлетворённости жизнью
и материальных трудностей. Корреляции рассчитываются **отдельно по годам**.

их через Excel. Документы структур XLS/XLSX, гайды HTML, D004 и данные предприятий
для выполнения кода не нужны.

## 2. Установка и запуск

Нужен **Python 3.10 или новее**. Откройте терминал в папке проекта.
Для изолированного окружения выполните:

```bash
python -m venv .venv
```

Активируйте окружение:

```bash
# macOS / Linux
source .venv/bin/activate
```

```powershell
# Windows PowerShell
.venv\Scripts\Activate.ps1
```

Установите зависимости и выполните анализ:

```bash
python -m pip install -r requirements.txt
python analyze.py
```

Если на macOS/Linux команда `python` недоступна, при создании окружения используйте
`python3`. После активации окружения доступна команда `python`.

По умолчанию используются `data/` рядом со скриптом и все четыре года.
Можно указать исходную папку архива, не копируя CSV:

```bash
python analyze.py --data-dir "/путь/к/synthetic_microdata_2021-2024_20260921"
```

Выбрать годы или место сохранения:

```bash
python analyze.py --years 2022 2023 2024
python analyze.py --years 2024
python analyze.py --output-dir ./my_results
python analyze.py --min-pairs 50
python analyze.py --no-plots --output-dir ./tables_only
```

Новые параметры v3:

- `--min-pairs`: минимальное число полных пар для расчёта корреляции, по умолчанию **30**. Если данных меньше или переменная постоянна, `rho` остаётся пустым, а `n_pairs` сохраняется. Используйте целое значение не меньше 3: текущий CLI сам не проверяет нижнюю границу.
- `--no-plots`: не создавать SVG; CSV и отчёты всё равно сохраняются. Флаг не удаляет SVG от прежнего запуска, поэтому для таблиц без старых графиков лучше использовать новую папку результатов.

Порог действует на внедиагональные корреляции, включая город/село. Диагональ
матрицы рисуется как 1 для непостоянных переменных и не является отдельным
подтверждением достаточного размера выборки.

Запустить тесты:

```bash
python -m unittest discover -s . -p "test_*.py" -v
```

## 3. Что рассчитывается

1. У текстовых значений удаляются внешние пробелы. Проверяются наличие файлов
   и колонок, год, уникальность ключей, территория, размер семьи и наличие
   респондентов в D008. Два пропущенных территориальных значения считаются
   согласованными; одно пропущенное и одно заполненное — несоответствием.
   Несовпадение KOL_CHL с числом членов — предупреждение; размер берётся из D008.
2. D008 агрегируется до одной строки на домохозяйство; D006 и D002 присоединяются
   через `left join`, чтобы отсутствие формы не удаляло семью из основы.
3. Рассчитываются площадь на человека, человек на комнату, доля детей,
   удовлетворённость жизнью/условиями/финансами, трудности оплаты ЖКУ/тепла,
   отсутствие водопровода в доме.
4. Сохраняются средние, медианы, перцентили и размеры групп. Для трёх бинарных
   показателей добавлены 95%-интервалы Уилсона: ЖКУ, отопление и отсутствие водопровода.
5. Рассчитываются корреляции Спирмена для каждого года и отдельно по городу/селу.
   Для каждой пары сохраняется число наблюдений с двумя валидными значениями.
6. Если не указан `--no-plots`, создаются четыре матрицы корреляций и график
   сравнения лет. На панели ЖКУ показаны интервалы Уилсона; для медианы площади
   интервалы не рассчитываются.
7. В `run_info.json` сохраняются выбранные годы, порог `min_pairs`, версии
   pandas/numpy, пути и SHA-256 всех входных CSV. Это позволяет проверить,
   что повторный анализ использует те же файлы.

`ρ` Спирмена находится от −1 до +1: знак показывает направление связи,
модуль — её силу. Используется ранжирование с усреднением связанных рангов.
Каждая пара ранжируется на собственных полных наблюдениях. Категориальные коды
региона не включены в матрицу как численные величины.

## 4. Что меняется между годами

| Показатель | 2021 | 2022 | 2023 | 2024 |
|---|---|---|---|---|
| Размер семьи, площадь, комнаты, водопровод | Да | Да | Да | Да |
| Удовлетворённость жизнью, условиями, финансами | Да | Да | Да | Да |
| Трудности оплаты коммунальных платежей | Да | Да | Да | Да |
| Возраст и доля детей | **Нет** | Да | Да | Да |
| Невозможность оплачивать тепло | **Нет** | Да | Да | Да |

В 2021 в D008 отсутствует `GOD_ROJD`: возраст не восстанавливается из других форм.
Число детей и их доля остаются пропущенными, а не нулевыми.

**Критическое отличие:** `ocenka.GR32` в 2021 — возможность заменить мебель,
а в 2022–2024 — возможность оплачивать и поддерживать тепло. Код учитывает это:
за 2021 показатель отопления пустой и отсутствует в графической матрице.

Набор кодов регионов изменяется с 2022 года. Таблицы регионов предназначены
для сравнения внутри года. Сопоставление региональной динамики потребует
отдельного согласования территориальных границ.

## 5. Где результаты

Полный запуск сохраняется в:

```text
results/years_2021_2022_2023_2024/
├── summary.md                              # Краткие результаты и ограничения
├── year_comparison.svg                     # Сравнение площади и трудностей ЖКУ
├── yearly_summary.csv                      # Средние, медианы, перцентили по годам
├── correlations_by_year.csv                # Корреляции, отдельная запись на год
├── groups_by_year.csv                      # Город/село, тип семьи, регион
├── correlations_by_year_and_settlement.csv # Корреляции по городу/селу и годам
├── households_all_years.csv                # Подготовленные микроданные с year
├── run_info.json                           # Годы, порог пар, версии, пути и SHA-256 данных
├── 2021/
├── 2022/
├── 2023/
└── 2024/
```

В папке каждого года находятся:

```text
households.csv                    # Одна строка на домохозяйство
correlations.csv                  # variable_a, variable_b, rho, n_pairs, shared_formula, year
correlations.svg                  # Матрица корреляций
correlations_by_settlement.csv     # Отдельно город и село
descriptive.csv                   # Описательная статистика
groups.csv                        # Статистика по группам
quality.json                      # Проверки и исключённые значения
```

Для подмножества лет создаётся отдельная папка, например `years_2022_2023_2024`.
Повторный запуск с теми же годами перезаписывает соответствующие результаты.
Порог `--min-pairs` не включён в имя папки: при сравнении порогов используйте
разные `--output-dir`. При `--no-plots` прежние графики остаются без изменений.
Исходные CSV не изменяются.

В сводных CSV:

- `households` — размер группы до исключения пропущенных ответов;
- `n_valid` — число валидных значений именно этого показателя;
- `mean` для бинарной переменной — доля **от 0 до 1**, для процентов умножить на 100;
- `ci_low`, `ci_high` — границы 95%-интервала Уилсона для бинарных показателей
  в шкале 0–1; для процентов умножить на 100. У остальных переменных поля пустые;
- `n_pairs` — число полных пар для конкретной корреляции;
- `shared_formula` — у переменных есть общий компонент формулы, поэтому связь
  может возникать математически (например, число людей и площадь на человека).

## 6. Правила качества и ограничения

Ключи: Связывание выполняется по year + NOMER (домохозяйство) и NOMP (человек). Межгодовых связей семей нет.

Исключения: Неположительные площади, некорректные номера респондентов и служебные коды (например, ответ 89 из 10-балльных шкал) фильтруются.

Применимость: Данные представляют собой независимые синтетические выборки по 12 000 домохозяйств. Результаты не являются официальной статистикой населения и не доказают причинно-следственные связи.

## 7. Проверка текущей версии
Все модульные тесты успешно пройдены.

### Какие графики использовать

1. `year_comparison.svg` — основной график для слайда о различиях между годами.
   Две панели: площадь на человека и доля трудностей ЖКУ. Укажите ограничения
   интервалов Уилсона из раздела 6; это уже существующий график новой версии.
2. `2024/correlations.svg` — матрица для слайда о связях. Показать крупно и выделить
   пары «жизнь—финансы» (0,769) и «площадь на человека—условия» (−0,014).
   Не использовать сильные связи переменных с общими формулами как независимые открытия.
3. В приложение — `2021/correlations.svg` или остальные годы для устойчивости
   результатов. Все четыре матрицы на одном слайде будут слишком мелкими.

Новых диаграмм город/село текущий `plots.py` не создаёт: для них есть
`groups_by_year.csv` и `correlations_by_year_and_settlement.csv`.
